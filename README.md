# elohz - Tech Gadgets & Action Accessories

Esta es una tienda premium desarrollada con **Next.js**, **React** y **Firebase** para **elohz Chile**.

## Características

- **Catálogo 3D**: Tarjetas de producto interactivas con efectos 3D.
- **Buscador de Soluciones con IA**: Utiliza Genkit y Gemini para recomendar productos basados en problemas descritos por el usuario.
- **Diseño Moderno**: Interfaz optimizada con Tailwind CSS y componentes ShadCN.
- **Integración con WhatsApp**: Comunicación directa para ventas personalizadas.

## Tecnologías

- **Framework**: Next.js 15 (App Router)
- **UI**: ShadCN UI + Tailwind CSS
- **IA**: Genkit (Google AI)
- **Backend**: Firebase

## Despliegue

El proyecto está configurado para desplegarse en **Firebase App Hosting**.
